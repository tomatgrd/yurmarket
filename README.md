# ЮрМаркет

Каталог юристов с анкетами, регистрацией, личными обращениями и перепиской.

## Запуск полной версии

Нужен Node.js 24+. Внешние зависимости не требуются.

```sh
npm start
```

Открыть http://127.0.0.1:3000. Аккаунты, анкеты, сообщения и обращения сохраняются в `data/yurmarket.sqlite`. Каталог `data` не публикуется в GitHub. Резервные копии базы нужно хранить отдельно.

```sh
npm test
npm run check
```

## Размещение

GitHub Pages публикует интерфейс и примеры анкет. GitHub Pages не выполняет Node.js и не размещает базу данных, поэтому регистрация, сообщения и обращения на нём недоступны. Интерфейс сообщает об этом и не показывает фиктивную успешную отправку.

Для полной версии нужен Node-хостинг с постоянным диском и HTTPS. Переменные: `NODE_ENV=production`, `HOST=0.0.0.0`, `PORT` (порт хостинга), `PUBLIC_ORIGIN` (полный HTTPS origin), `DATA_DIR` (каталог на постоянном диске). Сервер и интерфейс работают на одном origin. Не размещать базу на временном диске.

## Реализовано

- Пароли хешируются scrypt; сеансы используют HttpOnly cookies, в production — Secure.
- Чтение обращений и переписки ограничено участниками на сервере.
- Анкета публикуется из аккаунта юриста. Проверка документов не заявляется.
- Примеры анкет и дел обозначены как демонстрационные; отправить им сообщение нельзя.
- Встроенных административных паролей и автоматических ответов нет.

## Ограничения перед приёмом реальных данных

Email-подтверждение, восстановление пароля, модерация документов, вложения и email/push уведомления не подключены. Перед коммерческим запуском определить оператора, условия обработки данных, размещение и политику хранения. Не загружать конфиденциальные документы в публичный репозиторий.
